# Tres fuentes públicas / Three public sources

Copia [template.csv](template.csv) en una hoja de cálculo o úsalo como modelo para una tabla Markdown. / Copy the template into a spreadsheet or use it as a model for a Markdown table.

- **institution:** nombre institucional / institutional name.
- **url:** enlace al origen, con HTTPS / original HTTPS source.
- **purpose:** qué información publica, sin prometer disponibilidad / information published, without promising availability.
- **consulted_at:** fecha ISO, por ejemplo `2026-10-24` / ISO consultation date.
- **checked:** qué comprobaste tú: dominio, fecha, título / what you checked: domain, date, title.
- **limitations:** qué no sabes o no pudiste verificar / unknowns and unverified claims.

Empieza con las fuentes de la [guía](../../public/es/primeras-contribuciones.md). No pruebes formularios con datos reales ni recopiles casos personales. Una URL accesible no demuestra que un servicio esté funcionando. / Start with sources in the [guide](../../public/en/first-contributions.md). Do not test forms with real data or collect personal cases. A reachable URL does not prove a service is operating.
