# Seguridad y privacidad / Security and privacy

Este repositorio es público. No adjuntes datos personales, credenciales, registros de víctimas ni capturas que los contengan a issues o pull requests.

Si encuentras una exposición, contacta en privado a una persona moderadora de la comunidad en [Discord](https://discord.gg/yWhUUvrhpj), sin reenviar los datos en canales públicos. Indica únicamente dónde ocurre y el tipo de exposición; acuerda un canal privado antes de compartir detalles. No prometemos un plazo de respuesta ni operamos un servicio de emergencia.

Para responsables del repositorio: retirar un archivo del último commit no lo borra del historial. Evalúa el alcance, restringe la exposición y revoca cualquier credencial afectada; coordina la remediación sin reproducir los datos.

---

This repository is public. Do not attach personal data, credentials, victim records or screenshots containing them to issues or pull requests.

If you find an exposure, contact a community moderator privately through [Discord](https://discord.gg/yWhUUvrhpj), without forwarding data in public channels. Initially share only the location and type of exposure; agree on a private channel before sharing details. We do not promise a response time or operate an emergency service.

For repository maintainers: removing a file from the latest commit does not remove it from history. Assess the scope, restrict exposure and revoke affected credentials; coordinate remediation without reproducing the data.
